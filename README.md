# Titanic Data Cleaning and Preprocessing

## Problem Statement
The objective of this project is to clean and preprocess the Titanic dataset to make it suitable for analysis and machine learning applications.

## Dataset Details
- Dataset: Titanic Dataset
- Source: Kaggle Titanic Dataset

## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## Steps Performed
1. Loaded the Titanic dataset.
2. Checked dataset structure and summary.
3. Identified missing values.
4. Filled missing values in relevant columns.
5. Removed duplicate records.
6. Renamed columns for better readability.
7. Verified data types.
8. Saved the cleaned dataset.

## Results
- Missing values handled successfully.
- Duplicate rows removed.
- Dataset cleaned and prepared for further analysis.
- Cleaned dataset exported as CSV.

## Files Included
- Task1_Titanic.ipynb
- titanic.csv
- titanic_Cleaned dataset.csv

## Conclusion
Data cleaning is an essential step in data analysis. This project demonstrates how preprocessing techniques can improve data quality and prepare datasets for accurate analysis and machine learning tasks.
